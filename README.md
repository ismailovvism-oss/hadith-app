# Библиотека хадисов

Хадисы для русского читателя: свой перевод, передатчики, которых можно открыть нажатием, «Ясный шарх»
(живое изложение «Фатх аль-Бари») и арабский текст по желанию. Родственник `tafsir-app`, связан с `isnad` и базой
`Ислам/Хадисы` в Obsidian.

**Статус (05.11.2026):** приложение работает на компьютере, в интернет ещё не выложено. Выгружаются
Бухари и Муслим, переведены две первые книги Бухари (58 хадисов), они на вычитке у хозяина.

[правила перевода](перевод/ПРАВИЛА.md);
[пилот](ясный-шарх/пилот/пилот-1.md) — текст; [правила](ясный-шарх/ПРАВИЛА.md);
[Джами-50](ясный-шарх/Джами-50.md) — таблица 50 хадисов; [варианты](ясный-шарх/ВАРИАНТЫ.md) — как
выбирали шарх.
